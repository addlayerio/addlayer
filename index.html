Kravn

AI agent orchestration platform

Spin up specialized AI agents — one for security triage, one for ops, one for support — each with its own model, tools and knowledge base. Cron-scheduled automation or a team chat workspace, running entirely inside your own Kubernetes cluster. Your data never leaves.

  • Self-hosted

Verbora

Rust-native NLP toolkit

A high-performance natural language processing toolkit for Rust — 105 public APIs across seventeen crates covering tokenization, stemming, phonetics, string distance, TF-IDF, sentiment and more, with behavior locked down by a 526,341-case regression suite.

  • 105 APIs
  • 17 crates
  • 526k+ regression tests
